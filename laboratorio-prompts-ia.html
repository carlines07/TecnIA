Laboratorio práctico

Laboratorio de prompts de IA para estudiar mejor

Un buen prompt no sirve para copiar más rápido, sino para pensar mejor. En este laboratorio encontrarás instrucciones listas para usar con ChatGPT, Gemini, Copilot u otras herramientas de inteligencia artificial.

Prompt para resumir apuntes sin perder lo importante

Úsalo cuando tengas un texto largo y quieras quedarte con las ideas principales.

Actúa como profesor particular. Resume este texto en ideas principales, conceptos clave y posibles preguntas de examen. No elimines información importante y explica los términos difíciles con palabras sencillas: [pega aquí tus apuntes].

Prompt para entender un tema difícil

Ideal cuando lees algo y no consigues entenderlo bien.

Explícame este tema como si fuera principiante. Primero dame una explicación sencilla, luego un ejemplo práctico y después una mini pregunta para comprobar si lo he entendido: [tema].

Prompt para preparar un examen tipo test

Convierte tus apuntes en preguntas para practicar.

Crea 10 preguntas tipo test sobre estos apuntes. Dame 4 opciones por pregunta, marca la respuesta correcta al final y explica brevemente por qué es correcta: [pega aquí tus apuntes].

Prompt para hacer esquemas claros

Útil para ordenar temas antes de estudiar.

Convierte este contenido en un esquema jerárquico claro. Usa títulos, subtítulos y puntos clave. Señala también qué partes son más importantes para estudiar: [contenido].

Prompt para corregir una respuesta de examen

Sirve para practicar antes de entregar o estudiar.

Corrige esta respuesta como si fueras profesor. Dime qué está bien, qué falta, qué sobra y cómo podría mejorarla para sacar más nota. No la reescribas directamente, ayúdame a mejorarla: [respuesta].

Prompt para estudiar en modo oral

Perfecto para practicar como si alguien te preguntara.

Hazme preguntas una por una sobre este tema. Espera mi respuesta antes de corregirme. Si fallo, dame una pista y luego explícame la respuesta correcta: [tema].
